# Portfolio 2026 🚀

> **Google Cloud x Dev.to Challenge Submission**  
> January 1 - February 1, 2026

A high-performance, interactive developer portfolio built to demonstrate the power of **Vanilla JavaScript** and **CSS3** without the overhead of heavy frameworks. This project focuses on micro-interactions, physics-based animations, and a premium, responsive user experience.

## ✨ Key Features

### 🎭 Custom Animations

- **"The Brick Throw"** (Hero): A unique, physics-inspired entrance animation where elements fly in with momentum.
- **"Sequential Glide"**: Smooth, staggered reveals for project cards using `IntersectionObserver`.
- **"Spring Bounce"**: A playful, elastic entry effect for the contact form.
- **"Bento Tilt"**: Interactive, mouse-aware tilt effects on the "About Me" grid cards.

### 🌓 Dynamic Theme System

- Seamless **Dark/Light mode** toggle.
- Preferences persisted via `localStorage`.
- CSS Variables for instant, repaint-free theme switching.

## 💻 Tech Stack

- **Frontend**: HTML5, Semantic Markup
- **Styling**: CSS3, CSS Variables, Flexbox/Grid, Glassmorphism
- **Logic**: ES6+ JavaScript (Modules, Async/Await)
- **Icons**: Iconify
